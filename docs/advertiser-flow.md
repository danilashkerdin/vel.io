# Рекламодатель в Velo.io

## Обзор

Рекламодатели размещают на карте спонсорские зоны. Пользователи (велосипедисты), захватывая территории, пересекающиеся со спонсорской зоной, получают 10% от её бюджета. Платформа принимает платежи через Telegram Stars.

## Роль и регистрация

- При регистрации пользователь выбирает: **Велосипедист** или **Рекламодатель**.
- Роль фиксируется в `User.is_advertiser` и не меняется после регистрации.
- Рекламодателю не требуется имя пользователя — оно генерируется из email.

## Профиль рекламодателя

После входа рекламодатель может заполнить профиль:

- `business_name` — название бизнеса
- `contact_phone` — контактный телефон
- `contact_telegram` — Telegram для связи
- `website` — сайт/соцсеть
- `description` — описание бизнеса

## Спонсорские зоны

### Создание точки

1. Нажать **🏪 Создать зону** в меню или **+** на FAB.
2. Кликнуть на карте, чтобы поставить точку локации бизнеса.
3. Выбрать тариф:
   - **Старт** — 5000 ⭐ (маленькая точка)
   - **Стандарт** — 10000 ⭐ (средняя точка)
   - **Премиум** — 15000 ⭐ (большая точка)
4. Оплатить счёт в Telegram Stars.
5. После успешной оплаты вебхук активирует точку на карте.

### Управление зонами

В **📋 Мои спонсорские зоны** рекламодатель видит все свои зоны и может:

- редактировать название, описание, изображение, ссылку, цвет;
- приостанавливать/возобновлять показ зоны;
- пополнять бюджет зоны.

### Статистика

Каждая зона собирает метрики:

- `impressions` — количество показов зоны на карте;
- `clicks` — переходы по ссылке зоны.

Дашборд рекламодателя показывает суммарный бюджет, активные зоны, общее число показов и кликов.

## Финансы

- Все платежи рекламодателей фиксируются в `advertiser_payments`.
- Поддерживаются цели платежа: `create_zone`, `top_up`.
- Бюджет зоны хранится в `monthly_budget_rub` (условно: 1 Star ≈ 10 ₽ для метрик).

## Техническая реализация

### Модели

- `User.is_advertiser` — флаг роли.
- `AdvertiserProfile` — профиль рекламодателя.
- `SponsoredTerritory` — зона с полигоном, бюджетом, счётчиками, сроком действия.
- `AdvertiserPayment` — история платежей Stars.

### API

- `GET /api/advertiser/profile`
- `PUT /api/advertiser/profile`
- `GET /api/advertiser/dashboard`
- `GET /api/advertiser/payments`
- `POST /api/payment/create-star-invoice?purpose=sponsored&...` — создание/пополнение зоны
- `GET /api/my-advertiser-zones` — список своих зон
- `PATCH /api/my-advertiser-zones/{id}` — редактирование зоны
- `POST /api/my-advertiser-zones/{id}/pause`
- `POST /api/my-advertiser-zones/{id}/activate`

### Webhook

`POST /api/telegram/webhook` при `successful_payment`:

- `type: "sponsored"` → активирует/пополняет зону, обновляет `AdvertiserPayment`.
- `type: "premium"` → активирует Premium для пользователя.
